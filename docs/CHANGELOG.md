# 更新日誌

## v2.1_20251213 (2025-12-13)

### 新增功能
- 🖼️ 圖片保護完整支持：自動保留工作表的圖片保護設置，解鎖後會完整恢復所有保護選項
- 🔄 雙引擎支持：同時支持 openpyxl 和 win32com 兩種處理引擎，優先使用 COM 接口以獲得更好的性能和兼容性
- 🛡️ 增強的安全性：改進工作表保護處理機制，確保處理完成後正確恢復所有保護設置
- 📊 記憶體優化：實現垃圾回收和對象生命週期管理，提高大文件處理時的記憶體效率

### 修復問題
- 🐛 修復了合併單元格處理中的無限循環問題
- 🐛 解決了特定條件下數據類型錯誤的問題
- 🐛 修正了工作表保護恢復不完整的問題
- 🐛 修復了文件保存時可能出現的雙重保存導致損壞的問題
- 🐛 解決了部分環境下圖片丟失的問題
- 🐛 修復了編碼檢測和數據清洗相關的問題

### 改進優化
- ⚡ 性能提升：通過優化演算法和引入雙引擎機制，顯著提高了處理速度
- 🎨 用戶體驗改善：優化界面佈局和交互流程，提供更直觀的操作體驗
- 📈 穩定性增強：加強異常處理和錯誤恢復機制，減少程序崩潰的可能性
- 🗑️ 記憶體管理：實現主動垃圾回收，有效控制記憶體使用

## v2.0 (2025-11-20)

### 新增功能
- 🎨 全新圖形界面：基於 Tkinter 重新設計的現代化用戶界面
- 📁 支持多個工作表：可以在一個操作中處理多個工作表的不同區域
- 📐 靈活配置規則：支持自定義填入規則，包括起始單元格、數據數量等參數
- 📊 實時進度顯示：提供可視化的進度條和詳細的狀態信息
- 🔍 智能數據解析：自動識別和處理 TXT 文件中的有效數據

### 技術改進
- 🧠 模組化架構：重構代碼結構，提高可維護性和擴展性
- 🛡️ 完善的錯誤處理：增加全面的異常捕獲和用戶友好的錯誤提示
- 🚀 性能優化：優化數據處理演算法，提高大批量數據處理效率

## v1.0 (2025-10-15)

### 初始版本
- 📝 基礎功能實現：支持將 TXT 文件數據填入 Excel 模板
- 🔄 自動化處理：一鍵完成數據解析和填入操作
- 📂 文件格式支持：支持常見的 TXT 和 Excel 文件格式
- 🛠️ 基本錯誤處理：提供基礎的錯誤提示和日誌記錄功能
