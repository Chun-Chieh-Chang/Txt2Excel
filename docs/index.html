✨ 功能特點

🔍

智能解析

自動識別TXT文件編碼格式，智能解析數據結構，支持多種數據格式

🎯

精確填入

靈活配置填入規則，支持橫向填入，自動跳過合併儲存格和鎖定儲存格

🖼️

圖片保護

完整保留Excel文件中的圖片和格式，支持工作表保護設定的自動恢復

🔒

安全可靠

支持密碼保護的工作表，自動處理權限問題，確保數據安全

⚡

雙引擎支援

同時支持openpyxl和win32com兩種引擎，自動選擇最佳處理方式

🎨

圖形界面

友好的Tkinter圖形界面，操作簡單直觀，實時顯示處理進度

推薦

適合開發者和需要自定義功能的用戶

1

克隆倉庫

git clone https://github.com/Chun-Chieh-Chang/Txt2Excel.git
2

安裝依賴

pip install -r requirements.txt
3

運行程序

python src/main.py
前往 GitHub
