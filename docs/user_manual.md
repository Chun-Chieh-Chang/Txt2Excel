## 簡介

Txt2Excel v2.1_20251213 是一個高效的 Python 工具，用於將 TXT 格式的數據自動轉換並填入 Excel 報表中。該工具具有圖形化界面，支持多種編碼格式的 TXT 文件，能夠安全地填入 Excel 文件並保留原有格式和圖片。

### 主要特性
- 自動解析 TXT 數據文件
- 智能識別 Excel 結構
- 靈活配置填入規則
- 完整保留格式設置
- 圖片保護完整支持
- 合併單元格智能處理
- 雙引擎支持 (openpyxl + win32com)
- 記憶體優化與垃圾回收
- 多線程安全設計
- 完善錯誤處理機制

## 系統要求

- Windows 作業系統 (推薦 Windows 10 或更高版本)
- 至少 4GB RAM
- 至少 100MB 可用磁碟空間
- Microsoft Excel (推薦 Excel 2016 或更高版本，用於 COM 接口支持)

## 安裝指南

### 運行環境準備

1. 確保系統已安裝 Python 3.14 或更高版本
2. 安裝必要的依賴包：
   ```
   pip install -r requirements.txt
   ```

### 安裝依賴包

本工具需要以下 Python 套件：
- openpyxl
- pywin32
- chardet

可以通過以下命令一次性安裝：
```
pip install openpyxl pywin32 chardet
```

## 快速開始

### 方法一：使用可執行文件（推薦）
1. 雙擊運行 `dist/Txt2Excel.exe` 文件

### 方法二：使用批處理文件
1. 雙擊運行 `run_app.bat` 文件，這將自動設置所需的環境變量並啟動應用

### 方法三：通過命令行運行
1. 打開命令提示符 (CMD)
2. 切換到項目目錄：
   ```
   cd c:\path\to\Txt2Excel
   ```
3. 設置環境變量並運行程序：
   ```
   set TCL_LIBRARY=C:\Python314\tcl\tcl8.6
   set TK_LIBRARY=C:\Python314\tcl\tk8.6
   C:\Python314\python.exe src/main.py
   ```

## 詳細功能說明

### 數據預覽面板

數據預覽面板位於界面左側，用於顯示和預覽從 TXT 文件中提取的數據。

#### 功能特點：
- **文件選擇**：點擊"選擇文件"按鈕選擇要處理的 TXT 文件
- **自動編碼檢測**：自動檢測 TXT 文件的編碼格式（UTF-8、GBK 等）
- **數據顯示**：以列表形式顯示解析後的數據
- **統計信息**：顯示已解析數據的數量
- **數據操作**：
  - 清除：清除當前加載的所有數據
  - 重新載入：重新加載當前選擇的 TXT 文件

#### 數據格式要求：
TXT 文件應遵循以下格式：
- 每行包含一個等號 (=)
- 等號右側為需要提取的數據
- 示例：
  ```
  數據項1=123.45
  數據項2=67.89
  數據項3=45.67
  ```

### 填入配置面板

填入配置面板位於界面右側，用於配置 Excel 文件的填入規則。

#### 功能特點：
- **Excel 文件選擇**：點擊"選擇文件"按鈕選擇目標 Excel 文件
- **工作表信息**：顯示已加載 Excel 文件中的工作表數量
- **規則配置**：
  - 新增規則：添加新的填入規則
  - 編輯規則：修改現有的填入規則
  - 刪除規則：刪除選中的填入規則
  - 清空規則：刪除所有填入規則

#### 規則配置說明：
在"設定填入規則"對話框中，您可以配置以下參數：
- **工作表**：選擇要填入數據的目標工作表
- **起始儲存格**：指定填入數據的起始單元格（如 I26）
- **每頁筆數**：指定每個規則要填入的數據數量
- **方向**：目前固定為橫向填入（I, K, M, O...）

### 執行進度面板

執行進度面板位於界面底部，用於顯示數據填入的進度信息。

#### 顯示內容：
- **進度條**：可視化顯示整體執行進度
- **進度文本**：以百分比和數量形式顯示具體進度
- **狀態信息**：顯示當前正在處理的操作

## 使用示例

以下是一個完整的使用流程示例：

### 步驟 1：準備數據文件
創建一個名為 `sample.txt` 的文件，內容如下：
```
項目1=123.45
項目2=67.89
項目3=45.67
項目4=89.12
項目5=34.56
項目6=78.90
項目7=23.45
項目8=67.89
```

### 步驟 2：準備 Excel 模板
創建一個 Excel 文件，確保在某個工作表中有適當的佈局，並記住要填入數據的起始單元格地址（例如 I26）。

### 步驟 3：配置填入規則
1. 點擊右側面板的"選擇文件"按鈕，選擇準備好的 Excel 文件
2. 點擊"新增規則"按鈕
3. 在彈出的對話框中：
   - 選擇目標工作表
   - 設置起始儲存格為 I26
   - 設置每頁筆數為 8
4. 點擊"確定"保存規則

### 步驟 4：執行填入
1. 點擊界面底部的"開始執行"按鈕
2. 程序會自動開始填入數據
3. 觀察進度面板了解執行狀態
4. 執行完成後會彈出報告窗口顯示結果

## 常見問題解答

### 1. 出現 "Can't find a usable init.tcl" 錯誤怎麼辦？
這是由於 Tcl/Tk 函數庫路徑未正確設置造成的。請使用推薦的方法運行程序：
- 雙擊運行 `run_app.bat` 文件
- 或通過命令行設置環境變量後再運行

### 2. 界面顯示亂碼怎麼辦？
這是由於控制台編碼設置不正確導致的。批處理文件中已包含 `chcp 65001` 命令來設置 UTF-8 編碼。請確保使用推薦的方法運行程序。

### 3. 如何處理合併單元格？
程序能夠智能識別和處理合併單元格，確保每個合併區域只存儲一個數據值。當遇到合併單元格時，程序會自動跳過非主單元格，僅在主單元格填入數據。

### 4. 如何處理受保護的工作表？
當程序檢測到工作表受到保護時，會彈出密碼輸入框請求解鎖密碼。輸入正確的密碼後，程序會臨時解除保護進行數據填入，完成後自動恢復原有的保護設置。

### 5. 為什麼圖片有時無法正確保護？
程序已特別優化圖片保護功能，確保在處理過程中不會破壞圖片保護設置。如果仍有問題，請確認：
- 使用最新版本的工具
- Excel 文件中的圖片確實設置了保護屬性
- 工作表保護設置正確包含了圖片保護選項

### 6. 數據填入後格式發生變化怎麼辦？
程序在設計上盡量保留原有格式，但在某些情況下可能會出現格式變化。建議：
- 在 Excel 模板中使用樣式而非手動格式化
- 對於關鍵格式，可以使用 Excel 的"樣式"功能定義
- 填入數據後如有必要可手動調整格式
