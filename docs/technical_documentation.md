## 架構概述

Txt2Excel v2.1_20251213 採用模組化設計，主要由以下幾個核心組件構成：

1. **用戶界面層**：基於 Tkinter 構建的圖形用戶界面
2. **數據處理層**：負責 TXT 文件解析和數據提取
3. **配置管理层**：處理 Excel 文件加載和填入規則配置
4. **執行引擎層**：雙引擎實現（openpyxl + win32com）確保兼容性和性能
5. **進度監控層**：實時顯示處理進度和狀態

整個應用程序遵循 MVC（Model-View-Controller）設計模式，確保各組件之間的鬆耦合和高內聚。

## 模組說明

### DataPanel 類

DataPanel 是數據預覽面板，負責 TXT 文件的選擇、加載和數據顯示。

#### 主要功能：
- 文件選擇對話框
- 自動編碼檢測（使用 chardet 庫）
- 數據解析和清洗
- 數據預覽顯示
- 數據統計信息展示

#### 關鍵方法：
- `select_file()`：打開文件選擇對話框
- `load_txt_file()`：加載並解析 TXT 文件
- `display_data()`：在界面上顯示數據
- `clear_data()`：清除當前數據
- `reload_data()`：重新加載數據
- `get_data()`：獲取解析後的數據

#### 數據清洗邏輯：
1. 提取等號右側的內容
2. 移除非打印字符和多餘空白字符
3. 處理尾隨的無意義字符（如逗號、空格等）
4. 遇到第一個空值或無意義值時停止解析

### ConfigPanel 類

ConfigPanel 是配置面板，負責 Excel 文件的選擇、工作表信息顯示和填入規則配置。

#### 主要功能：
- Excel 文件選擇和加載
- 工作表信息讀取（使用 read_only 模式提高性能）
- 填入規則的增刪改查
- 規則驗證和存儲

#### 關鍵方法：
- `select_file()`：打開 Excel 文件選擇對話框
- `load_excel_file()`：加載 Excel 文件信息
- `add_rule()`：添加新規則
- `edit_rule()`：編輯現有規則
- `delete_rule()`：刪除選中規則
- `clear_rules()`：清空所有規則
- `refresh_rule_list()`：刷新規則列表顯示
- `get_config()`：獲取當前配置

### ProgressPanel 類

ProgressPanel 是進度面板，用於顯示數據填入的進度信息。

#### 主要功能：
- 進度條顯示
- 百分比和數量信息展示
- 當前處理狀態顯示

#### 關鍵方法：
- `update_progress()`：更新進度信息
- `reset()`：重置進度顯示

### RuleDialog 類

RuleDialog 是規則設置對話框，用於配置單個填入規則。

#### 主要功能：
- 工作表選擇（支持過濾顯示）
- 起始單元格設置
- 填入數量設置
- 實時預覽效果

#### 關鍵方法：
- `get_filtered_sheets()`：獲取過濾後的工作表列表
- `toggle_filter()`：切換工作表顯示模式
- `update_preview()`：更新預覽信息
- `ok()`：確認規則設置
- `cancel()`：取消規則設置

### LoadingDialog 類

LoadingDialog 是加載對話框，在加載大型 Excel 文件時顯示加載狀態。

#### 主要功能：
- 顯示加載提示信息
- 展示不確定進度條動畫

### MainWindow 類

MainWindow 是主窗口類，協調各個組件的工作並處理核心業務邏輯。

#### 主要功能：
- 界面佈局和組件管理
- 執行流程控制
- 核心填入邏輯實現
- 報告生成和顯示

#### 關鍵方法：
- `setup_ui()`：設置用戶界面
- `start_execution()`：開始執行填入
- `execute_filling()`：執行核心填入邏輯
- `show_report()`：顯示執行報告
- `reset_all()`：重置所有設置
- `show_help()`：顯示幫助信息

## 核心演算法

### 數據解析演算法

數據解析過程遵循以下步驟：

1. 自動檢測文件編碼格式
2. 逐行讀取文件內容
3. 對每一行：
   - 檢查是否包含等號
   - 提取等號右側內容
   - 清洗數據（移除無意義字符）
   - 驗證數據有效性
   - 若遇到無效數據則停止解析
4. 將有效數據存儲到列表中

### Excel 填入演算法

Excel 填入過程遵循以下步驟：

1. 驗證輸入數據和配置
2. 選擇合適的執行引擎（優先使用 win32com）
3. 對每條規則：
   - 加載對應工作表
   - 處理工作表保護（如有）
   - 根據起始單元格和方向計算填入位置
   - 檢查單元格是否為合併單元格的主單元格
   - 檢查單元格是否被鎖定
   - 填入數據
   - 更新進度信息
   - 恢復工作表保護（如有）
4. 保存並關閉 Excel 文件
5. 顯示執行報告

## 雙引擎實現

為了確保最佳的兼容性和性能，工具實現了雙引擎支持：

### openpyxl 引擎

openpyxl 是一個純 Python 實現的 Excel 處理庫，具有以下特點：
- 無需安裝 Microsoft Excel
- 跨平台兼容性好
- 對 Excel 文件格式支持全面
- 性能適中

#### 使用場景：
- 當 win32com 不可用時作為備選方案
- 處理簡單的 Excel 操作
- 在沒有安裝 Excel 的環境中使用

### win32com 引擎

win32com 是 Windows COM 接口的 Python 封裝，直接調用 Excel 應用程序，具有以下特點：
- 功能強大，支持 Excel 的所有特性
- 性能優異
- 需要安裝 Microsoft Excel
- 僅支持 Windows 平台

#### 使用場景：
- 優先使用的默認引擎
- 處理複雜的 Excel 操作
- 需要精確控制 Excel 特性時

## 異常處理

程序實現了完善的異常處理機制，包括：

1. **文件操作異常**：
   - 文件不存在
   - 權限不足
   - 文件被佔用
   - 編碼錯誤

2. **Excel 操作異常**：
   - 工作表不存在
   - 單元格坐標錯誤
   - 保護密碼錯誤
   - 保存失敗

3. **數據處理異常**：
   - 數據格式錯誤
   - 數值轉換錯誤
   - 記憶體不足

所有異常都會被捕獲並顯示友好的錯誤提示信息，同時記錄詳細的錯誤日誌便於調試。

## 性能優化

程序採用了多項性能優化措施：

1. **快速加載模式**：
   - 使用 openpyxl 的 read_only 模式快速讀取工作表信息
   - 避免不必要的數據加載

2. **延遲加載**：
   - 僅在實際需要時才完全加載 Excel 文件
   - 分步驟處理大型文件

3. **記憶體優化**：
   - 及時釋放不再使用的對象
   - 使用垃圾回收機制主動釋放記憶體

4. **併發處理**：
   - 在加載大型文件時使用後台線程
   - 避免界面凍結

## 記憶體管理

程序實現了嚴格的記憶體管理策略：

1. **對象生命週期管理**：
   - 明確的對象創建和銷毀時機
   - 避免循環引用

2. **垃圾回收**：
   - 在適當時候主動調用垃圾回收
   - 清空大型數據結構後及時回收

3. **資源釋放**：
   - 確保 Excel 對象正確關閉
   - 釋放 COM 對象引用
   - 關閉文件句柄

這些措施確保程序即使在處理大型 Excel 文件時也能保持穩定的記憶體使用。
